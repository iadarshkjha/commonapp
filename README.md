# Global Admissions 2027

Responsive, static admissions research workspace created from the supplied 103-page report dated October 14, 2026.

## Getting started

Open `index.html` in Chrome, Edge, Safari or Firefox. No web server, account, package manager or build step is needed. `index.html` loads `data.js`, `styles.css`, then `app.js`. Online fonts are optional. All core functionality works offline.

## Contents

- 26 ranked university records. Full profile text is retained in `data.js`, along with 26 detailed research-guide sections and explicitly numbered steps where the report contains them.
- 20 excluded university/scholarship route records, with original archive-table extracts.
- Complete 13-part research report in the Research & Sources view.
- Explore, search, filter, save, compare up to four, funding browser, Common App research matches, source links, university-specific research and checklists.
- Application status, application guide completion, private notes, personal tasks and JSON export/import stored locally in your browser.

## Important source limitations

This site presents the supplied research report; it does not independently validate universities' policies. Deadline text is presented conservatively because dates include uncertain/estimated values and research conflicts. Source data should not be interpreted as an official confirmation of admission, waiver, or scholarship eligibility. Check official websites before applying.

Several university guides in the source do not have explicit numbered Step 1 / Step 2 instructions. They are shown in full rather than inventing such instructions. The Common App page reflects mentions in profile text and is **not** a verified 2027 platform audit.

Progress is stored in `localStorage` under `ga27.v2`. Browser data clearing or private mode may erase progress; export backups regularly. The app does not sync across devices.
